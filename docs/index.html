Bulk Frame Rate Changer

Update the frame rate of all selected comps and footage in the project panel.

Download Script (.jsx) View GitHub Repository

Version 1.0.1 · Single .jsx file · Dockable ScriptUI Panel

How to use it

Installation

  1. Download the .jsx file using the button above.
  2. Open After Effects, then go to File → Scripts → Install ScriptUI Panel...
  3. Select the downloaded Bulk Frame Rate Changer.jsx file and confirm.
  4. After Effects will ask to restart — go ahead and restart it.
  5. Find it under Window → Bulk Frame Rate Changer.jsx.
  6. Select one or more items in the Project panel, enter a new frame rate, and click the matching button.
